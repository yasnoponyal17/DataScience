# Rice (Cammeo and Osmancik): карточка данных

## Назначение в курсе

Набор используется **только** в части «Реализация CART с нуля» Лабораторной работы 2: студент реализует бинарный классификатор CART без использования готового дерева для основного эксперимента. Это учебная задача классификации морфологических характеристик отдельных рисовых зёрен, а не система контроля качества пищевой продукции.

## Схема

UCI описывает 3 810 наблюдений, семь вещественных/целочисленных морфологических признаков и бинарную цель `Class`; пропусков нет.

| Поле | Тип в ARFF | Смысл по описанию UCI |
|---|---|---|
| `Area` | Integer | число пикселей внутри контура зерна |
| `Perimeter` | Real | длина контура зерна |
| `Major_Axis_Length` | Real | длина главной оси эквивалентного эллипса |
| `Minor_Axis_Length` | Real | длина малой оси эквивалентного эллипса |
| `Eccentricity` | Real | характеристика вытянутости эквивалентного эллипса |
| `Convex_Area` | Integer | площадь минимальной выпуклой оболочки |
| `Extent` | Real | отношение площади региона к ограничивающему прямоугольнику |
| `Class` | Nominal | `Cammeo` или `Osmancik` |

## Ограничения

Каждая строка — извлечённые из изображения признаки одного зерна. Набор не содержит изображений, сведений о партии, приборе, времени, географии или цене ошибки. Поэтому результат лабораторной нельзя переносить на реальные процессы сортировки без внешней валидации и предметной постановки задачи.
